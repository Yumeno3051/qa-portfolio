# QA Portfolio

Портфолио начинающего QA-инженера.

 О себе
Специализация: ручное функциональное тестирование веб-приложений.
Опыт: тестирование поисковых строк, форм регистрации, UI-элементов 
на 13 реальных сайтах (e-commerce, агрегаторы, порталы).

 Проекты
- **Telegram-бот для городских чатов** — Python + aiogram + SQLite.
- **Автотест TCP-соединения** — pytest, работа с сокетами.
- **Тестирование поисковых строк** — 217 тест-кейсов, 47 багов.

Навыки
- **Тестирование:** функциональное, UI/UX, регрессионное.
- **Инструменты:** DevTools, Excel, Lightshot, GitHub.
- **Технологии:** Python, SQLite, aiogram, REST API, pytest.
- **Документация:** Test Cases, Test Run, Bug Reports.
